Every prompt submitted and every response received through ConvoLink is symmetrically captured in a high-performance **SQLite FTS5 full-text search ledger** operating in WAL (Write-Ahead Logging) mode.

## Searching Your Architectural History

When an agent needs to recall why a specific trade-off or algorithm was chosen days ago:

```bash
convo search "SQLite WAL mode busy_timeout pragma" --limit 5
```

## Storage Invariants

- **Location:** The database lives at `$XDG_DATA_HOME/convolink/convolink.sqlite` (Linux) or `~/.local/share/convolink/convolink.sqlite`.
- **Concurrency:** Uses `PRAGMA journal_mode = WAL` and `PRAGMA synchronous = NORMAL`, allowing concurrent CLI queries and background agent reads without database lock contention.
- **Portability:** Export entire threads with `convo export <threadId> --format markdown`.
