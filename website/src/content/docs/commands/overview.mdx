ConvoLink provides a unified CLI exposed as both `convo` and `convolink`.

## Core Commands

| Command | Usage | Description |
| :--- | :--- | :--- |
| `doctor` | `convo doctor [--launch]` | Audits CDP latency, open AI tabs, and selector health. |
| `list` | `convo list` | Lists all active browser tabs on supported platforms. |
| `ask` | `convo ask <prompt> [flags]` | Sends prompt to an AI tab, streams completion, and extracts artifacts. |
| `compare` | `convo compare <prompt> [flags]` | Broadcasts prompt across models with Stage 2 arbitration. |
| `tab new` | `convo tab new <platform\|url>` | Spawns a clean background tab for an AI platform or URL. |
| `tab close` | `convo tab close <targetId>` | Closes a specific tab cleanly without touching browser. |
| `back` | `convo back [targetId]` | Navigates active tab back in browser history. |
| `undo` | `convo undo [targetId]` | Rollbacks an accidental chat reset to the previous conversation checkpoint. |
| `history` | `convo history [targetId]` | Lists recent checkpoints and thread URLs. |
| `resume` | `convo resume <threadId>` | Rehydrates a past conversation thread into a browser tab from SQLite. |
| `search` | `convo search <query>` | SQLite FTS5 search across conversation ledger turns and code. |
| `export` | `convo export <threadId>` | Exports a thread and code artifacts to Markdown/JSON. |
| `profile` | `convo profile <list\|select>` | Manages and switches browser profiles. |
| `ext` | `convo ext pair [--rotate]` | Manages extension pairing secrets for zero-flag mode. |
| `clean` | `convo clean` | Terminates orphaned debug processes and clears stale locks. |
| `mcp` | `convo mcp` | Runs JSON-RPC 2.0 MCP server over stdio. |

## Detailed Options for `convo ask`

```bash
convo ask "Implement the caching layer" --platform claude -w --out-dir .
```

### Flags

| Flag | Shorthand | Type | Description |
| :--- | :--- | :--- | :--- |
| `--platform` | `-p` | string | Target platform (`chatgpt`, `claude`, `deepseek`, `gemini`). |
| `--targetId` | `-t` | string | Target a specific browser tab by CDP ID or shorthand (`#1`, `#2`). |
| `--new` | `-n` | boolean | Start a fresh session before submitting. |
| `--open-tab` | | boolean | Spawn a brand-new tab in the background before submitting. |
| `--write-files` | `-w` | boolean | Extract files tagged with `// filepath:` to disk. |
| `--out-dir` | `-o` | path | Destination directory for written files (default: `./artifacts`). |
| `--think` | | boolean | Enable reasoning / deep-thinking mode (e.g. DeepSeek R1). |
| `--transport` | | string | Engine: `raw-cdp` (default), `extension-bridge`, `firefox-bidi`. |
| `--timeout` | | number | Milliseconds before request timeouts (default: `120000`). |
