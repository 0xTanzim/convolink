## Why an Agent Skill?

An autonomous coding agent (Antigravity, Cursor, Claude Code, Codex, OpenCode, Windsurf) starts each session with no prior knowledge of ConvoLink. Without a skill, it attempts to guess commands, hallucinates non-existent flags, or struggles with browser connection ports.

The **ConvoLink Agent Skill** packages the complete runtime contract into a standard `SKILL.md` bundle with progressive disclosure, providing:
- Explicit trigger conditions and quick-reference syntax.
- Machine-actionable exit code contracts (`convo onboard --json`).
- Concrete instructions for **Mozilla Firefox & Zen Browser** alongside Chrome, Brave, and Edge.
- Exhaustive reference manuals loaded on demand without polluting the agent's context window.

## 🚀 Installation

### Option A: Universal Agent Skills Standard (Recommended)

ConvoLink adheres to the universal Agent Skills specification (`skills add`):

<Tabs>
  <TabItem label="npx">
    ```bash
    npx skills add 0xTanzim/convolink
    ```
  </TabItem>
  <TabItem label="bunx">
    ```bash
    bunx skills add 0xTanzim/convolink
    ```
  </TabItem>
</Tabs>

### Option B: Native ConvoLink CLI Installer

```bash
# Install directly into your active coding harness:
convo skill install --harness antigravity   # or claude, cursor, codex, opencode

# List all supported destinations:
convo skill list
```

| Harness / Agent | Target Skill Path | Format |
|---|---|---|
| **Antigravity** | `.agents/skills/convolink/SKILL.md` | Standard `SKILL.md` + references |
| **Claude Code** | `.claude/skills/convolink/SKILL.md` | Standard `SKILL.md` + references |
| **OpenCode** | `.opencode/skills/convolink/SKILL.md` | Standard `SKILL.md` + references |
| **Codex** | `.codex/skills/convolink/SKILL.md` | Standard `SKILL.md` + references |
| **Cursor** | `.cursor/rules/convolink.mdc` | MDC Rule format |
| **Windsurf** | `.windsurfrules` | Context Rules format |

Custom project structure? Point it at an explicit directory:
```bash
convo skill install --dir ./custom-agent-context --harness claude
```

<Aside type="tip" title="Automatic References Bundling">
When you run `convo skill install`, ConvoLink automatically copies the complete `references/` directory alongside `SKILL.md` so all deep documentation is instantly available to your agent.
</Aside>

## 3-Layer Progressive Disclosure Architecture

ConvoLink's skill is engineered to maintain a lean context window while providing comprehensive domain knowledge:

```text
skills/convolink/
├── SKILL.md                  ← L2: Core instructions (< 150 lines, quick reference & guardrails)
└── references/               ← L3: On-demand deep documentation (loaded only when needed)
    ├── browsers.md           ← Firefox, Zen Browser, Chrome, Brave, Edge guide
    ├── cli.md                ← Exhaustive 12-command CLI manual
    ├── mcp.md                ← Full 11-tool MCP schema & structured error codes
    └── directives.md         ← Multi-file artifact extraction (// filepath:)
```

1. **Level 1 (Metadata ~100 tokens):** YAML frontmatter in `SKILL.md`. Loaded at agent startup to route relevant user queries.
2. **Level 2 (Instructions < 150 lines):** Main body of `SKILL.md`. Injected on-demand when the skill is activated. Contains timing contracts, session pinning rules, and anti-patterns.
3. **Level 3 (References on-demand):** Deep technical manuals in `references/`. Read only when specific deep syntax or edge-case troubleshooting is required.
