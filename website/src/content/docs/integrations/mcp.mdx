ConvoLink includes an ephemeral, lightweight Model Context Protocol (MCP) JSON-RPC 2.0 server over `stdio` designed specifically for autonomous AI coding agents (Google Antigravity, OpenAI Codex, Anthropic Claude Code, Cursor, Devin, Cline).

Instead of maintaining a continuous background daemon, ConvoLink boots in `< 30ms` with `< 1MB` heap, resolves browser connections Just-In-Time (JIT) when tools are invoked, auto-shuts down after inactivity (`--idle-timeout=15m`), and guarantees zero stale mutex locks on exit.

## Running ConvoLink MCP

You can launch the MCP server directly via `bunx` or `npx` with zero installation required:

```bash
# Instant run via bunx:
bunx -y convolink@latest mcp

# Or via global CLI:
convo mcp

# Pass custom inactivity auto-shutdown timeout:
bunx -y convolink@latest mcp --idle-timeout=30m
```

## The 11 Composite MCP Cognitive Tools

Rather than exposing 50+ micro-tools that pollute the agent's context window, ConvoLink exposes an ergonomic, domain-partitioned suite of **11 composite tools**:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                       11 Composite MCP Tools                           │
├────────────────────┬────────────────────┬──────────────────────────────┤
│ convo_ask          │ convo_compare      │ convo_doctor                 │
│ convo_list_tabs    │ convo_tab          │ convo_search                 │
│ convo_thread       │ convo_profile      │                              │
└────────────────────┴────────────────────┴──────────────────────────────┘
```

### 1. `convo_ask`
Submit a prompt to an AI browser tab (ChatGPT, Claude, DeepSeek, Gemini) with optional deep reasoning and web search grounding. Automatically extracts and persists generated code blocks to local workspace files.

#### Input Schema
```json
{
  "type": "object",
  "properties": {
    "prompt": { "type": "string", "description": "Prompt text to send to the browser AI" },
    "platform": { "type": "string", "enum": ["chatgpt", "deepseek", "gemini", "claude"], "description": "Target AI platform" },
    "targetId": { "type": "string", "description": "Optional targetId of a specific open browser tab" },
    "writeFiles": { "type": "boolean", "description": "Whether to extract and persist code blocks to local workspace" },
    "outDir": { "type": "string", "description": "Destination directory for extracted code blocks" },
    "newChat": { "type": "boolean", "description": "Whether to reset conversation to a fresh chat first" },
    "openTab": { "type": "boolean", "description": "Whether to spawn a new background tab" },
    "think": { "type": "boolean", "description": "Toggle deep thinking/reasoning mode (DeepSeek v4.1 Flash, Claude Thinking, GPT-6 Asta)" },
    "threadUrl": { "type": "string", "description": "Direct conversation URL to resume (skips convo_tab and convo_list_tabs)" },
    "workspaceRoot": { "type": "string", "description": "Project workspace root path (prevents process.cwd() $HOME leakage)" },
    "search": { "type": "boolean", "description": "Toggle live web search/DeepSearch grounding" }
  },
  "required": ["prompt"]
}
```

#### Sample JSON-RPC Request
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "convo_ask",
    "arguments": {
      "prompt": "Provide the complete TypeScript implementation of our event bus with strict typing.",
      "platform": "claude",
      "think": true,
      "writeFiles": true,
      "outDir": "./src/events"
    }
  }
}
```

### 2. `convo_compare`

```json

  "properties": {

  },
  "required": ["prompt"]
```

### 4. `convo_list_tabs`

#### Input Schema
```json

  "type": "object",
  "properties": {}
}
```

### 5. `convo_tab`
Lifecycle management for browser tabs: spawn a clean background tab (`new`), close an idle tab (`close`), navigate back (`back`), or rollback an accidental reset (`undo`).

#### Input Schema
```json
{
  "type": "object",
  "properties": {
    "action": {
      "type": "string",
      "enum": ["new", "close", "back", "undo"],
      "description": "Tab action to perform"
    },
    "target": {
      "type": "string",
      "description": "Platform name ('deepseek' | 'chatgpt' | 'gemini' | 'claude') or full URL for action 'new'"
    },
    "targetId": {
      "type": "string",
      "description": "Target ID of the tab for actions 'close', 'back', or 'undo'"
    }
  },
  "required": ["action"]
}
```

### 6. `convo_search`
Execute full-text FTS5 search across all historical conversation turns and extracted code snippets in the local SQLite ledger.

#### Input Schema
```json
{
  "type": "object",
  "properties": {
    "query": { "type": "string", "description": "Search query or keywords" },
    "limit": { "type": "number", "description": "Maximum number of results (default: 10)" }

  "required": ["query"]
}
```

### 7. `convo_thread`
Manage conversation threads: export thread history as Markdown or JSON (`export`), reopen a saved thread from SQLite into an active browser tab (`resume`), or inspect session checkpoints (`history`).

#### Input Schema
```json
{
  "type": "object",
  "properties": {
    "action": {
      "type": "string",
      "enum": ["export", "resume", "history"],
      "description": "Thread action to perform"
    },
    "threadId": { "type": "string", "description": "Thread ID for 'export' or 'resume'" },
    "targetId": { "type": "string", "description": "Tab targetId for 'history'" },
    "format": {
      "type": "string",
      "enum": ["markdown", "json"],
      "description": "Export format for action 'export' (default: markdown)"
    }
  },
  "required": ["action"]
}
```

---

### 8. `convo_profile`
Inspect and manage host browser profiles (Google Chrome, Edge, Brave): discover profiles and account emails (`list`), or bind the active workspace to a specific profile (`select`).

#### Input Schema
```json
{
  "type": "object",
  "properties": {
    "action": { "type": "string", "enum": ["list", "select"], "description": "Profile action (default: 'list')" },
    "target": { "type": "string", "description": "Profile index (e.g. '1'), account email, or name for action 'select'" }
  }
}
```

## Architectural Guardrails for Autonomous Agents

1. **Non-Blocking PolicyGate:** Prompts sent through `convo_ask` automatically sanitize sensitive secrets (`sk-...`, `ghp_...`, AWS keys, `.env` blocks) into `[REDACTED_SECRET]` before transmission.
2. **PID-Aware Mutex Locking:** Every tab operation acquires an exclusive, non-blocking lock. If another agent is streaming to a tab, ConvoLink advises targeting a different tab or waiting for the stream to settle.
3. **Zero Window-Focus Theft:** CDP `Emulation.setFocusEmulationEnabled` and `Page.setWebLifecycleState` are applied silently so background tabs continue streaming without stealing focus from the developer's active editor.
4. **Self-Correcting Guidance:** Every tool error returns an actionable remediation message teaching the agent how to correct its arguments on the very next turn.
