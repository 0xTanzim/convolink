ConvoLink runs as a local [Model Context Protocol](https://modelcontextprotocol.io/) server over `stdio`. An MCP client can use the same browser-backed workflows as the CLI: ask a web AI, compare model answers, inspect tabs, search saved conversations, and configure a workspace.

## Register the server

Use the configuration format supported by your MCP client. These examples show the server entry; follow the client's instructions for where to save it.

<Tabs>
  <TabItem label="Without global install">
    ```json
    {
      "mcpServers": {
        "convolink": {
          "command": "bunx",
          "args": ["-y", "convolink@latest", "mcp"]
        }
      }
    }
    ```
    This requires Bun 1.4 or newer. If using npm, set `command` to `npx` and use `[-y, convolink@latest, mcp]` as the arguments.
  </TabItem>
  <TabItem label="After global install">
    ```json
    {
      "mcpServers": {
        "convolink": {
          "command": "convo",
          "args": ["mcp"]
        }
      }
    }
    ```
    Install with `bun add -g convolink`, then restart or reload the MCP client so it starts the server.
  </TabItem>
</Tabs>

If the MCP client starts the server from a directory other than your project, configure the project root with the `CONVOLINK_WORKSPACE` environment variable or pass `workspaceRoot` to a tool that accepts it. See [client-specific setup](/convolink/integrations/ai-harnesses/).

## First session: onboard before browser work

Call `convo_onboard` when the agent first uses ConvoLink in a session. It reports readiness and the next required action. The action may be a command for the agent, a tool call, or an instruction that requires the person using the browser.

```text
MCP client -> convo_onboard -> follow nextAction -> convo_onboard until ready
```

Use `convo_status` to inspect the resolved browser, transport, and endpoint. Use `convo_setup` or `convo_profile` to change workspace configuration. `convo_doctor` checks the connection and browser readiness.

<Aside type="note" title="The browser profile is a user choice">
  ConvoLink can report available profiles and explain the next step. The person using the browser chooses which signed-in profile the project should use.
</Aside>

## Available tools

The server exposes 11 task-oriented tools. The MCP client's `tools/list` response is the source of truth for each current input and output schema.

| Tool | Purpose |
| :--- | :--- |
| `convo_onboard` | Check readiness and return one next step. Call first in a new session. |
| `convo_status` | Read the resolved browser, profile, transport, and endpoint. |
| `convo_setup` | Configure the workspace browser, profile, and transport. |
| `convo_doctor` | Diagnose browser connectivity and available AI tabs. |
| `convo_ask` | Send a prompt to one browser AI and wait for its response. |
| `convo_compare` | Ask multiple models in parallel and optionally synthesize their answers. |
| `convo_list_tabs` | Inspect available browser tabs. |
| `convo_tab` | Open or manage a ConvoLink tab. |
| `convo_profile` | List browser profiles or select one for this workspace. |
| `convo_search` | Search the local conversation history. |
| `convo_thread` | Export, resume, or inspect a saved conversation thread. |

## Ask one model

`convo_ask` can attach to an available tab or open a tab for the selected platform. Save the returned `tabId` and pass it as `targetId` to continue the same conversation. A `threadUrl` can be used to resume a known web conversation.

```json
{
  "prompt": "Review this migration plan for rollback gaps.",
  "platform": "claude",
  "workspaceRoot": "/path/to/project"
}
```

To write generated code to the workspace, set `writeFiles: true` and include `// filepath: relative/path` markers in the model's answer. Set `outDir` if you want a destination other than the default artifact directory.

## Compare model answers

Use `convo_compare` when independent answers are useful. Set `platforms` to the models you want and `arbitrate: true` to request a synthesis after they respond.

```json
{
  "prompt": "Compare the migration strategies and identify the safest rollout.",
  "platforms": ["chatgpt", "claude", "deepseek"],
  "arbitrate": true,
  "arbiter": "claude"
}
```
