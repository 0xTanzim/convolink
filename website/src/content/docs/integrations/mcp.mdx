ConvoLink includes an ephemeral, lightweight Model Context Protocol (MCP) JSON-RPC 2.0 server over `stdio` designed specifically for autonomous AI coding agents (Cursor, Windsurf, Claude Code, Antigravity).

Instead of maintaining a continuous background daemon, ConvoLink boots in `< 30ms` with `< 1MB` heap, resolves browser connections Just-In-Time (JIT) when tools are invoked, auto-shuts down after inactivity (`--idle-timeout=15m`), and guarantees zero stale mutex locks on exit.

## Running ConvoLink MCP

You can launch the MCP server directly via `bunx` or `npx` with zero installation required:

```bash
# Instant run via bunx:
bunx -y convolink@latest mcp

# Or via global CLI:
convo mcp

# Pass custom inactivity auto-shutdown timeout:
bunx -y convolink@latest mcp --idle-timeout=10m
```

## The Smart 8-Tool Cognitive Suite

ConvoLink exposes an ergonomic, domain-partitioned tool suite designed to balance complete agent capability against cognitive load and token bloat:

| Tool Name | Key Arguments | Outcome & Purpose |
| :--- | :--- | :--- |
| `convo_ask` | `prompt`, `platform?`, `targetId?`, `think?`, `search?`, `extractArtifacts?` | Submit prompt to an AI browser tab (ChatGPT, Claude, DeepSeek, Gemini). Supports deep reasoning (`think: true`), live web search (`search: true`), and auto-extracts code blocks (`// filepath:`) to local disk. |
| `convo_compare` | `prompt`, `platforms?`, `arbitrate?`, `arbiter?` | Broadcast a task across multiple frontier models in parallel and synthesize an authoritative consensus via Stage 2 Technical Arbiter. |
| `convo_doctor` | `fix?` | Inspect Chrome CDP port 9222 health, open AI tabs, and active browser profile. Pass `fix: true` to self-heal stale mutex locks and orphan processes. |
| `convo_list_tabs` | *(none)* | Discover open AI browser tabs with targetId, platform, title, and current URL without window-focus theft. |
| `convo_tab` | `action: "new" \| "close" \| "back" \| "undo"`, `platform?`, `targetId?` | Tab lifecycle management: spawn a background tab (`new`), close an idle tab (`close`), navigate back in history (`back`), or rollback an accidental reset (`undo`). |
| `convo_search` | `query`, `limit?` | SQLite FTS5 full-text search across past conversation turns, prompts, and extracted code artifacts. |
| `convo_thread` | `action: "export" \| "resume" \| "history"`, `threadId?`, `targetId?`, `format?` | Thread management: export history to Markdown/JSON (`export`), reopen a past conversation in the browser (`resume`), or inspect session checkpoints (`history`). |
| `convo_profile` | `action: "list" \| "select"`, `target?` | Multi-profile management: list discovered Chrome profiles with Google accounts (`list`) or bind workspace to a specific profile (`select`). |

<Aside type="tip">
  Every tool provides actionable, self-correcting error messages. When a required parameter is missing or ambiguous, ConvoLink instructs the agent on the exact corrective syntax for the next turn.
</Aside>
