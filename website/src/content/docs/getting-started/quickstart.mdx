Connect your local coding agent directly to your active browser tabs.

### 1. Run Instantly or Install Globally

   You can run ConvoLink instantly with zero setup, install via the universal 1-line script, or install globally via Bun or npm:

   <Tabs>
     <TabItem label="1-Line Universal (Recommended)">
       ```bash
       # Linux (Ubuntu, Debian, Fedora, Arch, Alpine) & macOS:
       curl -fsSL https://raw.githubusercontent.com/0xTanzim/convolink/main/scripts/install.sh | bash

       # Windows Native (PowerShell):
       irm https://raw.githubusercontent.com/0xTanzim/convolink/main/scripts/install.ps1 | iex
       ```
       *Creates a standalone executable wrapper at `~/.local/bin/convo` (or Windows `%LOCALAPPDATA%\convolink\bin\convo.cmd`) that invokes `bunx -y convolink@latest`. Requires zero root/sudo and installs zero background daemons.*
     </TabItem>
     <TabItem label="Instant (Zero Setup)">
       ```bash
       bunx -y convolink@latest doctor
       # or via npx:
       npx -y convolink@latest doctor
       ```
     </TabItem>
     <TabItem label="Package Managers">
       ```bash
       bun add -g convolink
       # or via npm:
       npm install -g convolink
       # or via pnpm:
       pnpm add -g convolink
       ```
     </TabItem>
     <TabItem label="From Source">
       ```bash
       git clone https://github.com/0xTanzim/convolink.git
       cd convolink
       bun install && bun link
       ```
     </TabItem>
   </Tabs>

### 2. Connect Your Real Browser

<Tabs>
  <TabItem label="Path A: Companion Extension (Recommended)">
    Download and install the zero-flag extension from [GitHub Releases](https://github.com/0xTanzim/convolink/releases):
    - **Chromium:** `convolink-companion-chrome.zip` for Chrome, Brave, Edge, and Chromium.
    - **Gecko:** `convolink-companion-firefox.zip` for Mozilla Firefox and Zen Browser.

    Load the unpacked folder into `chrome://extensions` or `about:debugging#/runtime/this-firefox`, then pair:
    ```bash
    convo ext pair
    ```
  </TabItem>
  <TabItem label="Path B: Direct Debugging Ports (Dev Profile)">
    Start your browser with dedicated automation port:
    ```bash
    # Chromium:
    google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/convo-chrome-dev

    # Firefox / Zen Browser:
    zen --remote-debugging-port 9223 -P <profile-name>
    ```
  </TabItem>
</Tabs>

### 3. Verify Connection Health

Run `convo doctor` to test protocol latency and detect all open AI tabs:

```bash
convo doctor
```

### 4. Submit Your First Query

Ask your upstream architect for specifications directly from the terminal:

```bash
convo ask --platform chatgpt "Explain the data model for our user authentication service."
```

<Aside type="tip">
  You can target specific tabs with shorthand `#1`, `#2` or by specifying `--platform claude`.
</Aside>

### 5. Install the Agent Skill for Your AI IDE

Make your coding agents (Antigravity, Cursor, Claude Code, OpenCode) aware of ConvoLink:

```bash
# Universal Agent Skills CLI:
npx skills add 0xTanzim/convolink

# Or native ConvoLink CLI:
convo skill install --harness antigravity   # or claude, cursor, codex, opencode
```
