This guide takes you from install to a first browser-backed AI request. You need [Bun 1.4 or newer](https://bun.sh) for the recommended Bun commands. ConvoLink runs locally and uses the signed-in browser session you choose.

## 1. Install or run once

Choose one option. You can start without a global install, add a global `convo` command, or use the one-line installer.

<Tabs>
  <TabItem label="Run without global install">
    ```bash
    bunx -y convolink@latest doctor
    ```
    If you use npm instead of Bun, run `npx -y convolink@latest doctor`.
  </TabItem>
  <TabItem label="Install globally">
    ```bash
    bun add -g convolink
    convo doctor
    ```
    Or install with `npm install -g convolink` or `pnpm add -g convolink`.
  </TabItem>
  <TabItem label="One-line installer">
    ```bash
    # Linux and macOS
    curl -fsSL https://raw.githubusercontent.com/0xTanzim/convolink/main/scripts/install.sh | bash

    # Windows PowerShell
    irm https://raw.githubusercontent.com/0xTanzim/convolink/main/scripts/install.ps1 | iex
    ```
    The installer adds a small `convo` wrapper that runs the latest package with `bunx`; it does not install a background service.
  </TabItem>
</Tabs>

## 2. Connect your browser

Choose the path that matches the browser profile you want to use.

<Tabs>
  <TabItem label="Chrome and Chromium browsers">
    For your everyday signed-in Chrome, Brave, Edge, or Chromium profile, install the [Companion Extension](/convolink/extension/overview/). It does not require browser debug flags or a restart.

    After loading the extension, pair it with the local CLI:

    ```bash
    convo ext pair
    ```

    Follow the command's instructions to copy the pairing token into the extension. Then check the connection with `convo doctor`.
  </TabItem>
  <TabItem label="Firefox and Zen">
    Firefox and Zen support native WebDriver BiDi. Start or connect the selected browser with:

    ```bash
    convo connect --firefox
    # or
    convo connect --zen
    ```

    The browser extension is optional for these browsers. See [Firefox and Zen connection details](/convolink/getting-started/browser-connection/#firefox-and-zen).
  </TabItem>
  <TabItem label="Dedicated Chromium profile">
    Use CDP when you want a separate automation profile, or when running headless or in CI. Chrome 136 and newer require a non-default user-data directory for remote debugging.

    ```bash
    google-chrome \
      --remote-debugging-port=9222 \
      --user-data-dir="$HOME/.convo/chrome-profile"
    ```

    Sign in to the AI sites in that dedicated profile, then run `convo doctor`. Do not add debug flags to the everyday Chrome profile.
  </TabItem>
</Tabs>

<Aside type="tip" title="Not sure which path to choose?">
  Use the Companion Extension for your everyday Chromium profile. Use native BiDi for Firefox or Zen. Choose CDP only when a separate Chromium profile is useful to you.
</Aside>

## 3. Check the connection

```bash
convo doctor
```

Doctor reports the active transport and whether ConvoLink can reach supported AI tabs. If it reports a setup problem, follow the remediation it prints; see [browser connection troubleshooting](/convolink/getting-started/browser-connection/).

## 4. Ask a question

Open a supported AI site in the connected browser, then send a prompt:

```bash
convo ask --platform chatgpt \
  "Review the authentication flow in this project and list the edge cases I should test."
```

ConvoLink returns the answer and records the exchange in its local conversation ledger. Continue the same browser conversation by targeting the returned tab, or use `convo search` to find it later.

## 5. Connect your coding agent (optional)

To let an MCP-compatible coding agent call ConvoLink, register this server in the agent's MCP configuration:

```json
{
  "mcpServers": {
    "convolink": {
      "command": "bunx",
      "args": ["-y", "convolink@latest", "mcp"]
    }
  }
}
```

If you installed ConvoLink globally, use `"command": "convo"` and `"args": ["mcp"]` instead. Open [MCP integration](/convolink/integrations/mcp/) for client-specific configuration and the available tools.

## 6. Give your agent project guidance (optional)

Install the ConvoLink agent skill so your coding harness knows when and how to use the CLI:

```bash
npx skills add 0xTanzim/convolink
```

You can also use the built-in installer: `convo skill install --harness cursor` (replace `cursor` with your supported harness). See [agent skills](/convolink/agents/skills/).
