Local coding agents often need a second opinion, web research, or a model that is not configured in their own runtime. ConvoLink lets an agent hand a task to an AI site in a browser session that you have already signed in to. The selected provider controls model access, account requirements, and any billing.

## The Borrowing Matrix

<CardGrid>
  <Card title="Extended Thinking / Reasoning" icon="star">
    **Reasoning modes exposed by the selected site**
    Pass `--think` when the selected platform supports a reasoning or extended-thinking mode. Availability and behavior depend on the current model and website.
  </Card>

  <Card title="Live Web Search Grounding" icon="magnifier">
    **Research grounded in the web**
    Pass `--search` when supported to ask the browser AI to use its live search feature. This can help with current documentation, releases, and migration guidance.
  </Card>

  <Card title="Multi-Model Consensus" icon="random">
    **Independent answers and synthesis**
    Use `convo compare` to ask several selected platforms in parallel. Optionally choose an arbiter to synthesize the responses. Provider account terms and charges still apply.
  </Card>

  <Card title="Living Mental Model" icon="document">
    **Conversation continuity**
    Continue a browser conversation with its prior decisions, rejected approaches, and context instead of re-entering it from scratch.
  </Card>
</CardGrid>

## Practical Examples

### Request a platform's reasoning mode
```bash
convo ask --platform deepseek \
  "Design a lock-free ring buffer for low-latency audio processing in C++. Explain the memory orderings and edge cases." \
  --think
```

### Borrowing Live Web Search Grounding
```bash
convo ask --platform chatgpt \
  "Check the current official documentation for this library's migration guidance. Summarize the relevant changes and link the sources you used."
```
