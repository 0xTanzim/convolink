# file-download-handler Specification

## Purpose
Enables the bridge to intercept sandbox download links, backend file endpoints, and blob URLs generated by Code Interpreter models, downloading them via the authenticated browser session directly to disk.

## Requirements

### Requirement: Sandbox Download Link Interception
The system SHALL scan completed model turns for downloadable file anchors, blob URLs, and sandbox export buttons.

#### Scenario: Turn contains Code Interpreter download link
- **WHEN** model output includes an anchor tag with a download attribute (`a[download]`) or URL matching `/backend-api/files/`
- **THEN** system extracts the download URL, intended filename, and file size metadata

### Requirement: Authenticated Binary Buffer Persistence
The system SHALL stream downloadable assets through the authenticated browser context via CDP and persist them to local storage.

#### Scenario: Downloading sandbox generated binary
- **WHEN** a valid download anchor is detected and `--write-files` is enabled
- **THEN** system fetches the asset using browser session credentials, writes the binary payload to target destination, and emits a download receipt
